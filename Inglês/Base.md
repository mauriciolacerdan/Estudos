# A1 — Base

## 1. Pronomes

| Inglês | Português                                         |
| ------ | ------------------------------------------------- |
| I      | eu                                                |
| you    | você / vocês (mesma palavra no singular e plural) |
| he     | ele                                               |
| she    | ela                                               |
| it     | ele / ela (coisas e animais)                      |
| we     | nós                                               |
| they   | eles / elas                                       |

## 2. Verbo _to be_ (ser / estar)

| Pronome         | Forma | Contração                |
| --------------- | ----- | ------------------------ |
| I               | am    | I'm                      |
| you / we / they | are   | you're / we're / they're |
| he / she / it   | is    | he's / she's / it's      |

- I'm tired. — Estou cansado.
- She is my sister. — Ela é minha irmã.
- I'm not at home. — Não estou em casa.
- Are you ready? — Você está pronto?

> Negativa: `not` depois do verbo. Pergunta: inverte (`Are you…?`). **Não usa do/does.**

## 3. Possessivos

| Inglês | Português                                      |
| ------ | ---------------------------------------------- |
| my     | meu / minha                                    |
| your   | seu / sua                                      |
| his    | dele                                           |
| her    | dela                                           |
| our    | nosso / nossa                                  |
| their  | deles / delas                                  |
| its    | dele / dela (coisa/animal; raro, não priorize) |

- My name is Maurício.
- This is her phone. — Este é o telefone dela.

## 4. Artigos, demonstrativos e plural

- `a` + som de consoante: a book
- `an` + som de vogal: an apple
- `the` = o / a / os / as (algo específico)

|          | perto | longe |
| -------- | ----- | ----- |
| singular | this  | that  |
| plural   | these | those |

Plural: `-s` (book → books). Irregulares: child → children, person → people.

## 5. Frases básicas (presente simples)

| Tipo       | Estrutura                        | Exemplo           |
| ---------- | -------------------------------- | ----------------- |
| Afirmativa | sujeito + verbo                  | I study English.  |
| Negativa   | don't / doesn't + verbo base     | She doesn't work. |
| Pergunta   | Do / Does + sujeito + verbo base | Does he work?     |

> Depois de `does` / `doesn't` o verbo fica na **base**: Does she **like**…? (não _likes_).

## 6. Presente simples

Hábitos, rotinas e fatos.

- I / you / we / they **work**
- he / she / it **works**

Exceções com he/she/it: have → **has**, go → **goes**, do → **does**.

- I study every day. — Estudo todos os dias.
- She works at a restaurant. — Ela trabalha em um restaurante.
- Do you like coffee? — Você gosta de café?

## 7. Verbos essenciais

| Verbo      | Significado                                     |
| ---------- | ----------------------------------------------- |
| be         | ser / estar                                     |
| have       | ter                                             |
| can        | poder / conseguir (uso normal)                  |
| be able to | conseguir (outros tempos: _I'll be able to go_) |
| come       | vir                                             |
| go         | ir                                              |
| know       | saber / conhecer                                |
| take       | pegar / levar / tomar                           |
| want       | querer                                          |
| say / tell | dizer / contar                                  |
| do / make  | fazer                                           |
| see        | ver / entender (_I see_)                        |
| give       | dar                                             |
| need       | precisar                                        |
| like       | gostar                                          |
| get        | obter / pegar / ficar (depende do contexto)     |

Expressões: have to go (ter que ir) · want to learn (querer aprender) · take a shower (tomar banho) · make a decision (tomar uma decisão) · do your best (dar o seu melhor) · Let me know (me avise)

## 8. Perguntas

| Palavra  | Significado                 |
| -------- | --------------------------- |
| what     | o quê / qual                |
| where    | onde                        |
| when     | quando                      |
| who      | quem                        |
| why      | por quê                     |
| how      | como                        |
| which    | qual (entre opções)         |
| how much | quanto (incontável / preço) |
| how many | quantos (contável)          |

- What's your name? — Qual é o seu nome?
- Where are you from? — De onde você é?
- What do you do? — Qual é a sua profissão?
- How are you? — Como você está?
- Could you repeat that? — Poderia repetir?
- What does this mean? — O que isso significa?

## 9. Preposições e conectores

- `in` — em / dentro: in the house
- `on` — sobre / em superfície: on the table
- `at` — ponto ou horário: at home, at 8 o'clock
- `to` — para: go to work
- `from` — de: from Brazil
- `and` e · `but` mas · `or` ou · `because` porque

## 10. Pronúncia

| Som         | Como fazer                      | Exemplo           |
| ----------- | ------------------------------- | ----------------- |
| th (surdo)  | língua entre os dentes, só ar   | think, thanks     |
| th (sonoro) | língua entre os dentes, com voz | the, this         |
| I'm         | "áim"                           | I'm tired         |
| -ed = /t/   | "t" no final                    | worked ≈ "uôrkt"  |
| -ed = /d/   | "d" no final                    | played ≈ "pleid"  |
| -ed = /id/  | sílaba extra, depois de t / d   | wanted ≈ "uóntid" |
